# CodX Media — Website (Full Package)

This package contains a lightweight, dark-themed, responsive single-page website for **CodX Media**.
Files included:
- index.html
- styles.css
- script.js
- /assets (placeholders)

## How to use
1. Extract the ZIP.
2. Edit files as needed (replace images in `assets/`, update content).
3. To host on GitHub Pages:
   - Create a repository (e.g. `codx-media`).
   - Upload all files to the repository root.
   - Enable GitHub Pages from `Settings → Pages` (branch `main`, folder `/ (root)`).
   - Visit: `https://<your-username>.github.io/codx-media/`

## Contact form
The included contact form is client-side demo only. To enable real email submissions:
- Use Netlify Forms, Formspree, or a simple server endpoint.
- Or connect to a server-side mailer (PHP/Node/Laravel).

## Assets
Replace `assets/placeholder-*.jpg` with your images (1200px recommended).
